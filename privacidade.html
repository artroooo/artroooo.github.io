Política de Privacidade

Última atualização: 27/09/2026

Esta política se refere à ferramenta interna do canal do YouTube "Fio da Miada", usada exclusivamente pelo responsável do canal.

Uso do YouTube API Services

Esta ferramenta usa o YouTube API Services. Ao utilizá-la, aplicam-se os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Quais dados são acessados

O único dado acessado é a autorização (OAuth) do próprio dono do canal, usada para:

  • ler estatísticas agregadas de desempenho dos vídeos do próprio canal (escopo yt-analytics.readonly).

O que não é feito

Nenhum dado de outros usuários é coletado, armazenado, compartilhado ou vendido. Esta ferramenta não usa cookies e não faz rastreamento de nenhum tipo.

Como os dados são armazenados

O token de autorização é armazenado de forma criptografada (como "encrypted secret" do GitHub Actions) e é usado apenas pelo processo automatizado que lê as estatísticas do canal. As estatísticas dos vídeos são mantidas apenas como números simples em um repositório privado do canal, usados unicamente para ajudar a escolher temas de vídeos futuros.

Retenção e exclusão de dados

  • O token de autorização fica guardado enquanto a ferramenta estiver em uso. Ao revogar o acesso nas configurações da Google, o token deixa de funcionar imediatamente, e o responsável remove o segredo armazenado no GitHub em até 7 dias.
  • As estatísticas obtidas pela API (apenas números agregados dos vídeos do próprio canal) são atualizadas periodicamente; qualquer estatística que não for atualizada por mais de 30 dias é excluída.
  • Nenhum dado obtido pela API é vendido, compartilhado com terceiros ou usado para publicidade.
  • Para solicitar a exclusão imediata de qualquer dado, basta enviar um e-mail para a7oo.casos@gmail.com; a exclusão é feita em até 7 dias.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento nas configurações de segurança da própria Google, em myaccount.google.com/permissions.
